# Flowscape Press Kit & Public Assets

This is the official public asset repository for **Flowscape**.

| Purpose | What you'll find |
|---------|-----------------|
| **CDN for Notion covers** | Stable, direct-link URLs for embedding cover images in Notion pages |
| **Press Kit** | Logos, banners, thumbnails, and fact sheets for content creators |
| **Per-project assets** | Scalable structure — every project gets its own folder |

---

## 📁 Repository structure

```
presskit/
├── studio-branding/       ← Global Flowscape brand assets
│   ├── logos/             ← Official logos (SVG, PNG, dark/light variants)
│   ├── colors/            ← Color palette files and swatches
│   └── fonts/             ← Licensed typefaces used by Flowscape
│
└── projects/              ← One folder per project / content series
    ├── _template/         ← Copy this to start a new project
    │   ├── covers/        ← Notion cover images
    │   ├── thumbnails/    ← YouTube thumbnails and social banners
    │   ├── logos/         ← Project-specific logos
    │   └── press-kit/     ← Fact sheets, screenshots, press releases
    └── <your-project>/    ← Created from the template above
```

---

## ✅ How to use these assets

### Embedding in Notion
Right-click any image file in this repository on GitHub and choose **Copy image address**.
Paste it as the cover URL in your Notion page.

### Downloading for videos or posts
Click any file → **Download raw file** (or use the raw URL directly).

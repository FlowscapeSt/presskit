# Flowscape Public Assets

This repository is the official public asset hub for **Flowscape**.

It serves two purposes:
- **CDN for Notion covers**: stable, public asset URLs for Notion cover images.
- **Press Kit for content creators**: downloadable branding assets for videos, posts, and media mentions.
